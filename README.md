# Conference Tracker — виджет Obsidian для дат форумов и выставок

[![tests](https://github.com/Masortim/conferences/actions/workflows/tests.yml/badge.svg)](https://github.com/Masortim/conferences/actions/workflows/tests.yml)

Плагин Obsidian, который следит за датами форумов, выставок, конференций и дней поля.
Для каждого события он хранит ближайшее проведение и **актуальное прошлое**: дату и место
текущего года, если событие уже прошло, или прошлого года, если оно ещё ожидается.
Глубокая история не показывается — в карточке только то, что действительно нужно
для планирования следующей поездки.

Из коробки добавлены три события:

| Событие | 2026 | «Прошлый раз» |
| --- | --- | --- |
| **Агронеделя** (Сибирская аграрная неделя) | 10–12 ноября, Новосибирск, МВК «Новосибирск Экспоцентр» — впереди | 5–7 ноября 2025, Новосибирск |
| **Технопром** (Международный форум технологического развития) | 26–28 августа, Новосибирск — уже прошёл | 26–28 августа 2026, Новосибирск |
| **День поля** (Всероссийский день поля) | 16–18 июля, Алтайский край, «Сибирский агропарк» — уже прошло | 16–18 июля 2026, Алтайский край |

Для 2027 года точные даты ещё не объявлены — в карточках показан ориентир
(«Дата уточняется», июль/август/ноябрь 2027).

> «День поля» в плагине ограничен Новосибирской областью и Алтайским краем.
> Проведения в других регионах (Ставрополье-2024, Волгоградская область-2025)
> не показываются и не добавляются автообновлением. Региональный «День поля
> Новосибирской области» — отдельное мероприятие; если он нужен, добавьте его вторым
> событием.

## Возможности

- **Ближайшее событие** — крупный счётчик «через N дней» или «идёт сейчас».
- **Список с фильтрами** — «Предстоящие», «Все», «Прошедшие»; группировка по месяцам.
- **Статусы** — «Через 2 дня», «Идёт · день 2 из 3», «Сегодня», «Завершилось».
- **Актуальное прошлое** — строка «Прошлый раз» показывает проведение текущего года,
  если оно уже прошло, или прошлого года, если событие ещё ожидается. Архива за
  позапрошлые годы нет.
- **Автообновление с официальных сайтов** — плагин читает страницу события,
  разбирает JSON-LD (`schema.org/Event`) и даты в тексте, добавляет новое проведение.
  Ручные даты при этом не перезаписываются: при расхождении появляется пометка
  «На сайте: …», а решение остаётся за вами.
- **Неуточнённые даты** — событие можно добавить с ориентиром «июль 2027», пока
  точная дата не объявлена.
- **Встраивание в заметки** — блок ` ```conferences ` с параметрами.
- **Четыре команды** и иконка календаря на ленте; опционально панель открывается при запуске.
- **Экспорт** — копирование списка в виде Markdown-таблицы с местами и прошлым проведением.
- **Без сборки и зависимостей** — обычный JS, работает на десктопе и мобильных.
- **Данные — один файл** `data.json` рядом с плагином, синхронизируется вместе с хранилищем.

## Превью

Посмотреть, как выглядит виджет, можно без установки: скачайте репозиторий и откройте
[`docs/preview.html`](docs/preview.html) в браузере двойным щелчком. Если браузер
блокирует локальные скрипты, запустите в корне репозитория
`python3 -m http.server 8000` и перейдите на `http://localhost:8000/docs/preview.html`.
Превью использует настоящие `main.js` и `styles.css`, поэтому вкладки, строка
«Прошлый раз» и переключение темы работают.

## Установка за 4 шага

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) или склонируйте его.
2. Скопируйте папку `conference-tracker` в `<хранилище>/.obsidian/plugins/`.
   Должно получиться `<хранилище>/.obsidian/plugins/conference-tracker/manifest.json`.
3. Перезапустите Obsidian (или выполните «Reload app without saving»).
4. Откройте **Настройки → Сторонние плагины** (Community plugins), включите плагин
   **Conference Tracker** и нажмите на иконку календаря на левой ленте — панель откроется справа.

Подробная инструкция — с путями для Windows/macOS/Linux, мобильными устройствами,
настройками и разбором проблем: [`docs/Установка-и-использование.md`](docs/Установка-и-использование.md).

## Быстрый старт

Открыть панель: `Ctrl/Cmd + P` → **Конференции: открыть панель конференций**.

Добавить событие: кнопка `+` в панели или команда **Добавить событие**. Чтобы внести
прошлые годы, откройте событие и добавьте строки в блоке «История проведений» —
именно они показываются как «Прошлый раз».

Обновить даты с сайтов: кнопка ↻ в заголовке панели или команда
**Обновить даты и места с сайтов**.

Встроить в заметку:

````markdown
```conferences
view: upcoming
limit: 5
```
````

Параметры блока: `view` (`upcoming` / `all` / `past`), `limit`, `hero`, `filters`,
`compact`, `title`.

Для «Технопрома» и «Дня поля» проведение 2026 года уже завершилось, поэтому оно
и показывается как прошлое; для «Агронедели» 2026 год ещё впереди, и в «Прошлом разе»
стоит 2025-й. Проведения 2024 года и «Дня поля» вне НСО/Алтая в плагин не входят.

Источники: [sibagroweek.ru](https://sibagroweek.ru/),
[форумтехнопром.рф](https://форумтехнопром.рф/),
[russian-field-day.ru](https://russian-field-day.ru/). Информация проверена
8 ноября 2026 года. Организаторы публикуют даты заранее не всегда, поэтому в плагине
есть режим «Дата уточняется» с ориентировочным месяцем — поставьте точную дату,
когда она появится, или включите автообновление.

## Структура репозитория

```
conference-tracker/            сам плагин — эту папку копируют в хранилище
  manifest.json                манифест Obsidian
  main.js                      вся логика и интерфейс (без сборки)
  styles.css                   стили под светлую и тёмную тему
docs/
  Установка-и-использование.md подробная инструкция
  preview.html                 интерактивное превью виджета
examples/
  Конференции - пример.md      пример заметки с встроенными виджетами
tests/                         тесты логики, разбора сайтов, отрисовки и плагина
package.json                   только для тестов (jsdom)
```

## Разработка

```bash
npm install       # нужен один раз, только для тестов
npm test          # 56 тестов: даты, проведения, разбор страниц, синхронизация, интерфейс
```

Плагин не требует сборки: Obsidian загружает `conference-tracker/main.js` как есть.
После правок достаточно перезагрузить плагин в настройках (или `Ctrl/Cmd + R`).

## Ограничения

- Автообновление разбирает официальную страницу эвристически: JSON-LD, затем даты
  в тексте. Если сайт отдаёт даты картинкой или требует JavaScript, ничего не найдётся —
  дату можно внести вручную.
- Ручное будущее проведение считается приоритетным: автообновление не затирает его,
  а показывает расхождение с сайтом.
- Сайт может блокировать запросы (403) или не отвечать — плагин покажет ошибку
  и продолжит работать офлайн.
- Счётчик считает календарные дни по локальной дате устройства, время начала не учитывается.
