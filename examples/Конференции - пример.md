# Календарь конференций

Пример заметки с виджетами плагина **Conference Tracker**. Скопируйте этот файл
в хранилище и откройте в режиме чтения — блоки ниже превратятся в виджеты.

## Ближайшие события

```conferences
view: upcoming
hero: true
filters: true
```

## Все события (не больше пяти)

```conferences
view: all
limit: 5
hero: false
compact: true
```

## Архив

```conferences
view: past
title: Прошедшие мероприятия
filters: false
```

## Как это устроено

Виджет встраивается блоком кода с языком `conferences`. Параметры пишутся построчно
в формате `ключ: значение`:

- `view` — `upcoming`, `all` или `past`;
- `limit` — сколько событий показать (0 — все);
- `hero` — показывать ли блок «Ближайшее событие»;
- `filters` — показывать ли вкладки-фильтры;
- `compact` — компактные карточки;
- `title` — заголовок над списком.

Сами события редактируются в боковой панели плагина (иконка календаря на ленте
или команда «Конференции: открыть панель конференций»). Даты и места плагин
загружает с официальных сайтов при запуске и при открытии панели. Изменения сразу
появляются во всех заметках с такими блоками.

> [!tip] Если даты ещё не появились
> Нажмите ↻ в панели — плагин перечитает источник. Если сайт ещё не опубликовал
> расписание, дату можно вписать вручную: откройте событие, выключите тумблер
> «Дата уточняется» и укажите даты и место. После проведения события в карточке
> появится строка «Прошлый раз».
