# Conference Tracker: установка и использование

Подробная инструкция к плагину-виджету для Obsidian: как установить, открыть панель,
добавлять события, встраивать виджет в заметки, где хранятся данные и что делать,
если что-то не работает.

## 1. Что делает плагин

Плагин добавляет в Obsidian виджет «Конференции» — он показывает:

- **ближайшее событие** и число дней до него (или «идёт сейчас»);
- **список событий** с фильтрами «Предстоящие / Все / Прошедшие»;
- **карточки** с датами, местом, заметкой, ссылкой на сайт и прошлым проведением;
- **статусы**: «Через 2 дня», «Завтра», «Сегодня», «Идёт · день 2 из 3»,
  «Последний день», «Завершилось 5 дней назад», «Дата уточняется»;
- **события без точной даты** — с ориентировочным месяцем, пока организаторы не
  объявили даты.

Виджет доступен в двух местах:

1. **Правая боковая панель** — постоянный дашборд.
2. **Блок `conferences` в любой заметке** — например, в заметке-дневнике или
   в MOC (Map of Content) по мероприятиям.

Виджет не ходит в интернет и не парсит сайты: даты вы вносите вручную, зато плагин
работает офлайн и ничего не отправляет наружу.

## 2. Требования

- Obsidian **1.4.0 или новее** (десктоп или мобильный).
- Включённые сторонние плагины (выключенный «Ограниченный режим» / Restricted mode).
- Сборка не нужна: плагин — это три файла, которые Obsidian загружает напрямую.

## 3. Установка

Плагина нет в каталоге Community plugins, поэтому он ставится вручную — копированием
папки. Это один раз и без терминала.

### 3.1. Подготовка

1. Скачайте репозиторий: на странице GitHub нажмите **Code → Download ZIP** и
   распакуйте архив (или `git clone`).
2. Внутри архива найдите папку **`conference-tracker`**. В ней должны лежать
   `manifest.json`, `main.js` и `styles.css`.

### 3.2. Windows

1. Откройте папку вашего хранилища (vault). Обычно это
   `C:\Users\<имя>\Documents\<Название хранилища>`.
2. Включите показ скрытых файлов: **Проводник → Вид → Показать → Скрытые элементы**.
3. Перейдите в `.obsidian\plugins`. Если папки `plugins` нет — создайте её.
4. Скопируйте туда папку `conference-tracker` целиком.

Итог: `...\<хранилище>\.obsidian\plugins\conference-tracker\manifest.json`.

### 3.3. macOS

1. В Finder откройте папку хранилища (часто `~/Documents/<Название хранилища>`).
2. Нажмите **Cmd + Shift + .** (точка), чтобы увидеть скрытые папки.
3. Перейдите в `.obsidian/plugins` (создайте `plugins`, если её нет).
4. Скопируйте папку `conference-tracker`.

### 3.4. Linux

```bash
cp -r conference-tracker "<путь к хранилищу>/.obsidian/plugins/"
```

Скрытые файлы в файловом менеджере включаются сочетанием **Ctrl + H**.

### 3.5. Мобильные устройства

Плагин работает и на iOS/iPadOS, и на Android, но папку нужно скопировать в хранилище
через файловый менеджер:

- **iOS/iPadOS:** приложение «Файлы» → «На iPhone» → `Obsidian` → `<хранилище>` →
  `.obsidian` → `plugins`. Включите показ скрытых файлов, если папка не видна.
- **Android:** файловый менеджер → папка хранилища → `.obsidian/plugins`.
  На Android 11+ доступ к `Android/data` может быть ограничен — проще держать
  хранилище в `Documents`.

Альтернатива для обоих: положите папку `conference-tracker` в хранилище на компьютере,
а затем синхронизируйте хранилище (Obsidian Sync, iCloud, Dropbox, Syncthing, Git).
В Obsidian Sync включите **Settings → Sync → Vault configuration sync → Installed community plugins**
(«Синхронизировать установленные плагины»), иначе на телефоне плагин не появится.

### 3.6. Включение

1. Перезапустите Obsidian (или `Ctrl/Cmd + R` → «Reload app without saving»).
2. **Настройки → Сторонние плагины** (Community plugins).
3. Если видите предупреждение об ограниченном режиме — нажмите **Turn off restricted mode**
   / «Отключить ограниченный режим» и подтвердите.
4. В разделе **Установленные плагины** найдите **Conference Tracker** и включите
   переключатель.

Если плагин не появился в списке — см. [раздел 12](#12-частые-проблемы).

## 4. Первый запуск

После включения плагин сразу добавляет три события: «Агронеделя», «Технопром»,
«День поля».

Открыть панель можно тремя способами:

1. **Иконка календаря** на левой ленте (ribbon).
2. **Палитра команд**: `Ctrl/Cmd + P` → *Конференции: открыть панель конференций*.
3. Автоматически при запуске — включите настройку **«Открывать панель при запуске Obsidian»**.

Панель открывается справа. Её можно перетащить в другую область или закрепить.

## 5. Как устроена панель

Сверху вниз:

- **Заголовок** — количество событий и подсказка, через сколько дней ближайшее.
  Кнопки: `+` (добавить) и обновление.
- **Фильтры** — «Предстоящие» (по умолчанию), «Все», «Прошедшие». В скобках-счётчиках
  видно количество событий в каждой вкладке. Вкладка «Прошедшие» скрывается, если
  в настройках отключён показ прошедших.
- **Ближайшее событие** — крупная цифра «через N дней». Если событие идёт сегодня —
  «Идёт · день 2 из 3», если это последний день — «Финал».
- **Список** — сгруппирован по месяцам, события без даты — в блоке
  «Дата уточняется», завершившиеся — в блоке «Прошедшие».
- **Карточка** — название, полное название, бейдж статуса, даты, место, заметка,
  категория, ссылка «Сайт ↗» и прошлое проведение. Кнопки редактирования и удаления
  появляются при наведении (на телефоне видны всегда).

Цвет левой полосы карточки зависит от категории: форум — синий, выставка — зелёный,
конференция — фиолетовый, день поля — оранжевый.

## 6. Работа с событиями

### 6.1. Добавить событие

1. Нажмите `+` в панели (или выполните команду **Добавить событие**).
2. Заполните поля:
   - **Название** — обязательное, именно оно показывается крупно.
   - **Полное название** — необязательное уточнение (например, «Сибирская аграрная неделя»).
   - **Категория** — форум, выставка, конференция, день поля или другое (влияет на цвет).
   - **Дата начала / окончания** — формат `ГГГГ-ММ-ДД`; в стандартном календаре
     Obsidian подставляет формат сам.
   - **Место**, **Сайт**, **Заметка** — необязательные, но полезные.
   - **Прошлое проведение** — свободный текст, например «2026 — 26–28 августа».
3. Нажмите **Добавить**.

Если дата окончания окажется раньше даты начала, плагин попросит исправить.

### 6.2. Событие без точной даты

Если организаторы ещё не объявили даты:

1. Включите тумблер **«Дата уточняется»** — поля точных дат скроются.
2. Укажите **ориентировочный месяц** (например, `2027-08`).

В виджете появится бейдж «Дата уточняется» и подпись «Ориентир: август 2027».
Когда точная дата будет объявлена, откройте событие, выключите тумблер и впишите даты.

### 6.3. Изменить или удалить

- Наведите курсор на карточку → значок карандаша (изменить) или корзины (удалить).
- Удаление подтверждается отдельным окном.
- Отменить удаление нельзя, но можно вернуть три события по умолчанию в настройках.

### 6.4. Ссылки

Кнопка **«Сайт ↗»** открывает адрес в браузере. Можно вводить адрес без `https://` —
плагин добавит схему сам.

## 7. Виджет внутри заметки

Вставьте в любую заметку блок кода с языком `conferences`:

````markdown
```conferences
view: upcoming
hero: true
```
````

В режиме чтения (и в реальном времени) на месте блока появится виджет. Он использует те
же события, что и боковая панель: изменили дату в панели — обновился и блок в заметке.

### 7.1. Параметры блока

| Параметр | Значения | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `view` (или `mode`) | `upcoming`, `all`, `past` | `upcoming` | Начальная вкладка |
| `limit` | число | `0` — без ограничения | Сколько событий показать |
| `hero` | `true` / `false` | `true` | Показывать блок «Ближайшее событие» |
| `filters` | `true` / `false` | `true` | Показывать вкладки-фильтры |
| `compact` | `true` / `false` | `true` в заметке | Компактные карточки |
| `title` | текст | — | Заголовок над виджетом |

Неизвестные параметры игнорируются, регистр не важен.

### 7.2. Примеры

Только ближайшие пять событий, без блока «Ближайшее»:

````markdown
```conferences
view: upcoming
limit: 5
hero: false
```
````

Полный список с архивом и своим заголовком:

````markdown
```conferences
view: all
title: Мероприятия 2026–2027
compact: false
```
````

Только прошедшие — для раздела «Архив»:

````markdown
```conferences
view: past
filters: false
```
````

Если после правки блока виджет не обновился, закройте и снова откройте заметку — так
Obsidian перерисовывает блоки кода.

## 8. Настройки

**Настройки → Сторонние плагины → Conference Tracker** (шестерёнка) или
**Настройки → Conference Tracker** в левом списке.

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Показывать прошедшие события | включено | Вкладка «Прошедшие» и архив в «Все» |
| Показывать события с неуточнённой датой | включено | События с ориентиром вместо даты |
| Показывать блок «Ближайшее событие» | включено | Крупный счётчик над списком |
| Открывать панель при запуске Obsidian | выключено | Автоматически открывать панель |

Внизу — кнопки **«Скопировать список как Markdown»** (таблица в буфер обмена)
и **«Сбросить события к исходным»** (возвращает три события по умолчанию).

## 9. Команды и горячие клавиши

Палитра команд (`Ctrl/Cmd + P`), поиск по слову «конференц»:

| Команда | Что делает |
| --- | --- |
| Конференции: открыть панель конференций | Открывает/показывает панель |
| Конференции: добавить событие | Открывает форму нового события |
| Конференции: скопировать список событий как Markdown | Кладёт таблицу в буфер обмена |

Своё сочетание клавиш: **Настройки → Горячие клавиши** → найдите команду → назначьте.

На ленте слева есть иконка календаря, её можно перетащить в другое место.

## 10. Где хранятся данные

Все события и настройки лежат в одном файле:

```
<хранилище>/.obsidian/plugins/conference-tracker/data.json
```

- **Резервная копия** — просто скопируйте `data.json`.
- **Перенос в другое хранилище** — скопируйте всю папку `conference-tracker` вместе
  с `data.json`.
- **Синхронизация** — файл синхронизируется вместе с настройками плагинов, если в
  Obsidian Sync включён пункт «Installed community plugins». При синхронизации через
  Git добавьте `.obsidian/plugins/conference-tracker` в репозиторий хранилища.
- **Только события, без настроек** — при необходимости можно отредактировать JSON
  вручную: структура описана в [разделе 14](#14-устройство-плагина). Перед правкой
  сделайте копию файла.

Формат дат в данных — `ГГГГ-ММ-ДД` (`2026-11-10`), ориентировочный месяц — `ГГГГ-ММ`.

## 11. Как поддерживать даты актуальными

Плагин не обновляет даты сам — и это осознанно: даты конференций объявляют в разное
время, а автоматический парсинг сайтов часто ошибается. Рабочий ритм такой:

1. Раз в месяц откройте панель: события с бейджем «Дата уточняется» — кандидаты на проверку.
2. Зайдите на официальный сайт по кнопке «Сайт ↗».
3. Появилась дата — откройте событие, выключите «Дата уточняется», впишите начало и конец.
4. После проведения события добавьте строку в «Прошлое проведение» и перенесите даты
   на следующий год (или снова включите «Дата уточняется»).

Например, после «Агронедели» (10–12 ноября 2026) логично записать
«2026 — 10–12 ноября» и поставить ориентир на ноябрь 2027.

## 12. Частые проблемы

**Плагина нет в списке установленных**

- Проверьте путь: должно быть `.obsidian/plugins/conference-tracker/manifest.json`.
  Частая ошибка — вложенная папка `conference-tracker/conference-tracker`.
- Убедитесь, что `.obsidian` — папка именно вашего хранилища, а не другого.
- Перезапустите Obsidian полностью, а не просто закройте окно.

**Плагин есть, но при включении ошибка «Failed to load plugin»**

- Проверьте, что в папке лежит `main.js` (не `main.ts`, не `main.js.txt`).
- Обновите Obsidian до 1.4.0 или новее.
- Откройте консоль разработчика (`Ctrl/Cmd + Shift + I`) и посмотрите текст ошибки.

**Не открывается панель**

- Попробуйте команду из палитры команд — возможно, панель просто скрыта в другой
  области экрана.
- На очень узком окне правая панель может быть свёрнута — разверните её.

**В заметке вместо виджета — пусто или код**

- Плагин выключен. Включите его в настройках и переоткройте заметку.
- Блок должен начинаться ровно с ```` ```conferences ```` (три обратные кавычки и слово
  `conferences`).

**Счётчик показывает «не то» число дней**

- Счётчик считает календарные дни по локальной дате устройства и не учитывает время
  начала. «Завтра» означает, что событие начнётся на следующий календарный день.

**Не сохраняются изменения**

- Хранилище доступно только для чтения (сетевой диск, папка без прав записи).
- Конфликт синхронизации: закройте Obsidian на других устройствах и повторите.

**Сбросились события**

- Восстановите `data.json` из резервной копии или нажмите «Сбросить события к исходным»
  в настройках.

## 13. Удаление плагина

1. **Настройки → Сторонние плагины** → выключите Conference Tracker.
2. Удалите папку `.obsidian/plugins/conference-tracker` (вместе с `data.json`, если
   данные больше не нужны).

## 14. Устройство плагина

```
conference-tracker/
  manifest.json   манифест: id, имя, версия, минимальная версия Obsidian
  main.js         логика дат, панель, блок кода, модальные окна, настройки
  styles.css      стили на переменных темы Obsidian
```

Сборки нет: `main.js` — обычный CommonJS-файл, который Obsidian загружает напрямую.
Даты и статусы считаются в чистых функциях (`parseISODate`, `getEventState`,
`formatRangeRu`, `sortEvents`), поэтому их легко проверить тестами.

Запуск тестов (нужен Node.js 20+):

```bash
npm install
npm test
```

Тесты проверяют разбор дат, склонения, статусы, сортировку, фильтры, отрисовку виджета
в боковой панели и в заметке, валидацию формы события.

Структура `data.json`:

```json
{
  "version": 1,
  "events": [
    {
      "id": "agroneweek",
      "title": "Агронеделя",
      "fullTitle": "Сибирская аграрная неделя",
      "category": "Выставка",
      "start": "2026-11-10",
      "end": "2026-11-12",
      "expectedMonth": "",
      "place": "Новосибирск · МВК «Новосибирск Экспоцентр»",
      "url": "https://sibagroweek.ru/",
      "note": "…",
      "previous": "2025 — 5–7 ноября",
      "tentative": false,
      "createdAt": "2026-11-08T10:00:00.000Z"
    }
  ],
  "settings": {
    "showPast": true,
    "showTentative": true,
    "showHero": true,
    "openOnStartup": false
  }
}
```

- `tentative` вычисляется автоматически: если `start` пустой, событие считается
  событием с неуточнённой датой.
- `end` можно не указывать — событие будет однодневным.
- Неизвестные поля игнорируются, поэтому файл можно править вручную без риска
  сломать плагин (но лучше сделать копию).
